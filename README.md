# 🚗 Car Parking Shop - Telegram Mini App

Telegram мини-приложение для продажи внутриигровых товаров из игры CarParking.

## 📋 Описание

Полнофункциональный магазин с административной панелью для управления товарами и системой заказов через Telegram бота.

### Основные возможности

- 🛍️ **Каталог товаров** с изображениями и видео
- 🛒 **Быстрое оформление заказов** в один клик
- 👨‍💼 **Административная панель** для управления товарами
- 📱 **Адаптивный дизайн** для мобильных устройств
- 🔐 **Аутентификация через Telegram**
- 📦 **Поддержка изображений и видео**

## 🚀 Установка и настройка

### Требования

- Python 3.8+
- Telegram бот (токен от @BotFather)
- Доступ к серверу для хостинга

### Шаг 1: Клонирование репозитория

```bash
git clone <your-repo-url>
cd telegram-shop-miniapp
```

### Шаг 2: Установка зависимостей

```bash
pip install -r requirements.txt
```

### Шаг 3: Настройка переменных окружения

Создайте файл `.env` на основе `.env.example`:

```bash
cp .env.example .env
```

Отредактируйте `.env` и заполните следующие переменные:

```env
# Токен бота от @BotFather
TOKEN=your_bot_token_here

# ID администратора (узнать можно через @userinfobot)
ADMIN_ID=123456789

# Username администраторов через запятую
ALLOWED_ADMINS=username1,username2

# Настройки сервера (опционально)
HOST=0.0.0.0
PORT=8000
```

### Шаг 4: Создание директорий

```bash
mkdir -p media
```

### Шаг 5: Настройка Telegram бота

1. Создайте бота через @BotFather
2. Получите токен и добавьте в `.env`
3. Настройте Web App в боте:
   - Отправьте команду `/newapp` в @BotFather
   - Выберите вашего бота
   - Укажите название приложения
   - Укажите URL вашего сервера (например: `https://yourdomain.com/public/shop.html`)
   - Загрузите иконку (опционально)

4. Создайте кнопку для открытия магазина:
   - Отправьте команду `/setmenubutton` в @BotFather
   - Выберите вашего бота
   - Укажите текст кнопки (например: "🛍️ Открыть магазин")
   - Укажите URL Web App

## 🏃 Запуск

### Вариант 1: Использование start.sh (Linux/Mac)

```bash
chmod +x start.sh
./start.sh
```

### Вариант 2: Запуск вручную

Откройте два терминала:

**Терминал 1 - FastAPI сервер:**
```bash
python server.py
```

**Терминал 2 - Telegram бот:**
```bash
python bot.py
```

### Вариант 3: Использование uvicorn напрямую

```bash
# Сервер
uvicorn server:app --host 0.0.0.0 --port 8000

# Бот (в другом терминале)
python bot.py
```

## 📱 Использование

### Для покупателей

1. Откройте бота в Telegram
2. Нажмите кнопку "Открыть магазин" в меню
3. Просмотрите каталог товаров
4. Нажмите "🛒 Заказать" на понравившемся товаре
5. Дождитесь подтверждения заказа

### Для администраторов

1. Откройте админ-панель: `https://yourdomain.com/public/admin.html`
2. Добавляйте новые товары через форму
3. Редактируйте существующие товары
4. Удаляйте неактуальные товары
5. Получайте уведомления о заказах в Telegram

## 🔧 API Endpoints

### Публичные

- `GET /products` - Получить список всех товаров

- `POST /edit-product` - Редактировать товар

## 🐛 Решение проблем

### Бот не отвечает

- Проверьте правильность токена в `.env`
- Убедитесь что бот запущен (`python bot.py`)
- Проверьте логи на наличие ошибок

### Не загружаются товары

- Убедитесь что FastAPI сервер запущен
- Проверьте что файл `products.json` существует
- Проверьте права доступа к файлу

### Ошибка 403 в админ-панели

- Убедитесь что ваш username добавлен в `ALLOWED_ADMINS` в `.env`
- Перезапустите сервер после изменения `.env`

### Не загружаются изображения

- Проверьте что директория `media/` существует
- Проверьте права доступа к директории
- Убедитесь что файлы сохраняются в `media/`
